# toutes les dix minutes — cent quarante-quatre fois par jour — userait le cache
# du dépôt pour rien ; six roues PyPI s'installent en une trentaine de secondes.
#
# Les versions sont bornées par majeure : une tâche planifiée qui se met à
# échouer parce qu'une dépendance a changé de comportement pendant la nuit est
# le contraire de ce qu'on attend d'une chaîne de fraîcheur.
